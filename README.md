# Çengel Bulmaca · Crossword

İpuçlarını çöz, kelimeleri kesiştir!

Bir hücreye dokun; altta ipucu görünür. Klavyeyle yanıtı yaz. Aynı hücreye yeniden dokunmak yönü (→ ↓) değiştirir. Bütün ızgara dolunca bulmaca biter.

100.000 bölüm; her bölüm üretilir ve kurallara göre doğrulanır. Kelime Oyunları merkez uygulamasının oyunu; ortak motor: [kelime-motoru](https://github.com/taktemurr-ops/kelime-motoru).
